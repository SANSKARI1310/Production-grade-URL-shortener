Production-grade-URL-shortener
A production-oriented URL shortening and analytics platform built with Java and Spring Boot, progressively evolving toward a distributed, cache-optimized, event-driven backend. The project will be divided in certain phases corresponding to different tech stacks that i will add eventually which will follow my backend-codex repo. 1ST PHASE Phase 1 --> Core Domain, Storage & ID Strategy

Flyway database migrations
Domain model
Distributed ID generation
Base62 encoding
URL validation and normalization
HTTP redirect handling
Standardized API error handling
Integration testing with Testcontainers
